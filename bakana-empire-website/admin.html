Admin — Gestão de Imóveis

Forma simples e rápida de adicionar ou editar listagens sem precisar de base de dados.

Nota: Esta página é apenas para o administrador (você / William). Não a publique no menu público do site. O ficheiro principal a editar é js/properties-data.js.

Como adicionar um novo imóvel

1 Abra o ficheiro js/properties-data.js no editor de código (VS Code, etc.).
2 Copie um objecto existente (por exemplo o último de arrendamento ou de venda).
3 Cole-o no final da lista PROPERTIES (antes do ];) e altere os campos: 
{
  id: "rent-09",                    // ID único (obrigatório)
  type: "rent",                     // "rent" ou "sale"
  category: "vivenda",              // apartamento | vivenda | escritorio | comercial | penthouse | terreno
  title_pt: "Vivenda T3 — Exemplo",
  title_en: "T3 Villa — Example",
  location: "Benfica, Luanda",
  municipality: "Benfica",          // usado no filtro
  price: 750000,                    // número sem pontos
  priceLabel_pt: "/ mês",
  priceLabel_en: "/ month",
  bedrooms: "T3",
  status: "disponivel",             // disponivel | novo | usado | reservado
  modality_pt: "Semestral",
  modality_en: "Semester",
  description_pt: "Descrição completa em português...",
  description_en: "Full description in English...",
  features: ["Piscina", "Garagem", "Semestral"],
  images: [
    "https://url-da-foto-1.jpg",
    "https://url-da-foto-2.jpg",
    "https://url-da-foto-3.jpg"
  ],
  whatsappMsg_pt: "Olá, tenho interesse na Vivenda T3 em Benfica",
  whatsappMsg_en: "Hello, I'm interested in the T3 Villa in Benfica",
  featured: false                   // true = aparece na página inicial
}
4 Guarde o ficheiro e faça o deploy (push para GitHub / Cloudflare Pages). O imóvel aparece automaticamente nas páginas de Arrendamento ou Venda.

Campos importantes

  • id — deve ser único (ex: rent-09, sale-04)
  • type — controla se aparece em Arrendamento ou Venda
  • municipality — valor exacto usado no filtro (Patriota, Benfica, Talatona…)
  • images — array de URLs. A primeira é a foto principal. Pode adicionar quantas quiser (carrossel automático).
  • featured: true — mostra o imóvel na secção “Destaque” da página inicial

Onde colocar as fotos

Pasta de imagens do site: 

assets/
  properties/   ← fotos dos imóveis (arrendamento & venda)
  village/      ← fotos do Bakana Village
  about/        ← foto do William, diploma, etc.
  brand/        ← logo, ícones da marca

Exemplo — imóvel com ID rent-01: 

"images": [
  "assets/properties/rent-01-1.jpg",
  "assets/properties/rent-01-2.jpg",
  "assets/properties/rent-01-3.jpg"
]

Também pode usar links externos (Unsplash, ImgBB, Cloudinary, Google Drive público) enquanto não tiver as fotos finais.

Páginas que usam estes dados

  • Home — imóveis com featured: true
  • Arrendamento — todos com type: "rent" + filtros
  • Venda — todos com type: "sale" + filtros
  • Página de detalhe — property.html?id=ID
